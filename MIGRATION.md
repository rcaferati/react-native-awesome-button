# Migration Guide

## From 3.1.0 to the 3.2.0 compatibility bridge

Version 3.2.0 preserves every 3.1.0 call site while exposing the shared Awesome Button vocabulary. It does not silently enable a new geometry mode.

| Existing API              | Bridge API                            | Current behavior                                                                                        | Future major intent                                                                  |
| ------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Outer `style`             | `containerStyle`                      | Both remain valid; `containerStyle` wins conflicts.                                                     | Rename the typed visual surface to `style` after removing the outer-style collision. |
| `activityColor`           | `buttonStyle.activityColor`           | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `activeOpacity`           | `buttonStyle.activeOpacity`           | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `backgroundActive`        | `buttonStyle.backgroundActive`        | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `backgroundColor`         | `buttonStyle.backgroundColor`         | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `backgroundPlaceholder`   | `buttonStyle.backgroundPlaceholder`   | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `backgroundProgress`      | `buttonStyle.backgroundProgress`      | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `borderColor`             | `buttonStyle.borderColor`             | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `borderRadius`            | `buttonStyle.borderRadius`            | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |

| `borderBottomRightRadius` | `buttonStyle.borderBottomRightRadius` | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `borderWidth`             | `buttonStyle.borderWidth`             | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `paddingHorizontal`       | `buttonStyle.paddingHorizontal`       | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `paddingTop`              | `buttonStyle.paddingTop`              | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `paddingBottom`           | `buttonStyle.paddingBottom`           | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `textFontFamily`          | `buttonStyle.textFontFamily`          | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `textLineHeight`          | `buttonStyle.textLineHeight`          | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| `textSize`                | `buttonStyle.textSize`                | The typed field wins.                                                                                   | Remove the top-level alias.                                                          |
| Stack-oriented `height`   | `faceHeight`                          | `faceHeight` wins while `height` retains 3.1.0 geometry.                                                | Make `height` mean face height.                                                      |
| `width="auto"`            | `autoWidth` on `ThemedButton`         | An explicit `autoWidth` decision wins.                                                                  | Keep one canonical sizing vocabulary.                                                |
| Eventful `onLongPress`    | `onLongPressAction`                   | The eventless action wins and supports assistive activation; the legacy callback remains physical-only. | Make the eventless action canonical.                                                 |
| `raiseLevel`              | `buttonStyle.raiseAmount`             | The typed field wins.                                                                                   | Remove `raiseLevel`.                                                                 |
| `borderLeftBottomRadius`  | `buttonStyle.borderBottomLeftRadius`  | The correctly named typed field wins.                                                                   | Remove the misspelled alias.                                                         |
| `backgroundDarker`        | `buttonStyle.depthColor`              | The typed field wins.                                                                                   | Remove the legacy alias.                                                             |
| `backgroundShadow`        | `buttonStyle.shadowColor`             | The typed field wins.                                                                                   | Remove the legacy alias.                                                             |
| `textColor`               | `buttonStyle.foregroundColor`         | The typed field wins.                                                                                   | Remove the legacy alias.                                                             |
| `springRelease={false}`   | Native spring release                 | The legacy non-spring path remains callable.                                                            | Use the native spring unconditionally.                                               |
| `twitter`                 | `x`                                   | `twitter` remains callable; `AwesomeButtonVariant` accepts `x`.                                         | Review removal only in a separately authorized major.                                |

React Native still retains its 3.1.0 direct geometry defaults and 100 ms press fallback. Other governed ports use the neutral 140 ms fallback. This remains explicit cross-platform debt rather than an implicit behavior change.

Review the checked-in API report and `CHANGELOG.md` before adopting the 3.2.0 bridge.
